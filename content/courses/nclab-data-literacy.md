### Course Description

NCLab's Data Literacy program is a project-based series covering the core data analyst toolkit: exploratory analysis and predictive modeling in Excel, data cleaning and dashboarding in Sheets, and interactive dashboard design in Power BI.

### Projects

<details class="course-section">
<summary>Palmer Penguins Review: A Predictive Model Approach</summary>
<p>Explored the Palmer Penguins dataset in Excel and built a linear regression model showing flipper length as a reliable predictor of body mass.</p>
